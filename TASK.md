# Carousel — C++ containment-плазмоїд для панелі KDE Plasma 6 (форк Grouping)

## Мета
Панельний плазмоїд-контейнер, у який можна Drag&Drop-ом кидати інші плазмоїди (таймер, монітор мережі, Command Output тощо),
і який показує на панелі ОДИН із них за раз: [<] [compactRepresentation поточного аплета] [>] [▲].
Стрілки / колесо миші гортають; ▲ відкриває попап із fullRepresentation поточного аплета.
Опція «follow updates»: коли якийсь із вкладених аплетів змінив стан/вміст — карусель перемикається на нього.
Порядок аплетів — як їх вкинули; у попапі можна переставляти (мінімум: список з кнопками вгору/вниз).

## Основа
Форк `applets/grouping` з kdeplasma-addons тієї ж версії, що встановлена (Plasma 6.6.6, Kubuntu 26.04):
`git clone --depth 1 -b v6.6.6 https://invent.kde.org/plasma/kdeplasma-addons.git` (або відповідний тег).
Grouping = C++ `GroupingContainment` + QML package; саме C++-containment дає можливість вміщувати аплети.
Перейменувати в `org.uw5eg0.carousel.container` (+ containment id), НЕ чіпати оригінальний grouping.

## Обмеження
- Все лише в цій теці та в системі збірки; залежності ставити через apt (plasma-dev / libplasma-dev / kf6 dev / qt6 dev / extra-cmake-modules — перевірити реальні назви пакетів у Kubuntu 26.04).
- Інсталяція плагіна — у `~/.local` де можливо; якщо C++-плагін неминуче має лежати в системному шляху — зупинитись і сказати, не робити sudo-install без підтвердження.
- Існуючий QML-плазмоїд `org.uw5eg0.carousel` (~/workspace/plasma-carousel) не чіпати — це окрема річ.
- Не вигадувати API: читати код grouping і хедери з установлених dev-пакетів.
